**Perception and Prescriptions – ML Project**

This project explores how machine learning can be applied to analyze a larger dataset related to perceptions and prescriptions. The goal is to uncover insights, apply predictive modeling techniques, and evaluate model performance in a structured way.
Built using Python and Google Colab, this project demonstrates the end-to-end ML workflow — from data preprocessing to model building and evaluation.

**Features**
Data preprocessing (cleaning, handling missing values, feature engineering)
Exploratory Data Analysis (EDA) with visualizations
Application of multiple Machine Learning algorithms
Performance evaluation using accuracy, precision, recall, and F1-score
Well-structured Jupyter Notebook for reproducibility

**Tech Stack**
Python 3
Google Colab / Jupyter Notebook
Libraries:
pandas, numpy
matplotlib, seaborn
scikit-learn

**Results:**

1.Key insights were derived from the dataset through EDA
2.Machine learning models were trained and evaluated
3.The best-performing model achieved promising accuracy and balanced performance metrics

**Learning Outcomes:**

1.Hands-on experience with real-world dataset handling
2.Practical application of ML algorithms for prediction and analysis
3.Strengthened understanding of model evaluation and selection
